# Alertas de UFT

`current.json` y `exports/alerts.csv` conservan el historial de alertas del ciclo:
refutaciones de controles y dependencias que requirieron revisión. Consultar el
estado más reciente de la entidad en `exports/knowledge.json`: una alerta previa
de revisión puede haber quedado resuelta por una auditoría posterior.

El namespace UFT no modifica `ALERTAS.md` del BRAIN ni anuncia que se resolviera
una meta física. Las incidencias operativas y las científicas se distinguen por
tipo. Sin cambios significativos, el observador no crea otra alerta.
