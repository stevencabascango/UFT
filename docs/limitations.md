# Límites y siguientes comprobaciones

Las tres metas siguen abiertas. Cada propuesta distingue el programa deseado del
modelo acotado realmente desarrollado. No hay predicción gravitatoria nueva
confrontada con datos ni una afirmación de novedad mundial verificada.

| Programa | Límite actual | Próxima comprobación prioritaria |
|---|---|---|
| Googly | DGLA abstracta; no geometría twistorial física ni reconstrucción Einstein. | Definir complejo real con pesos, firma, gauge y mapa de helicidades; calcular su primera obstrucción mixta. |
| Unificación | Filtro de acoplamiento de vectores sin gravedad ni materia. | Proponer contenido de campos y acción mínimos; contar restricciones, signos, anomalías y límites antes de extenderla. |
| Gravedad cuántica | Un intertwiner y reloj ideal impuesto; no restricciones completas, continuo ni UV. | Modelo con reloj material y retroacción; distinguir Gauss, difeomorfismos y restricción Hamiltoniana y controlar el sector de aproximación. |
| Puente entre programas | Correspondencia abstracta BV/DGLA bajo grados y paridad compatibles. | Construir el diccionario físico; con fermiones conservar graduación adicional. |

La exactitud de las pruebas finitas no elimina obstrucciones en órdenes superiores
ni garantiza convergencia. Para el reloj, el producto físico se define sobre
soluciones generalizadas y no mediante la norma cinemática (L^2(dT)).

Los perfiles y las habilidades son objetivos de diseño. El benchmark y los
subagentes de esta entrega no evalúan excelencia científica de cada ficha. La
revisión interna puede compartir errores de modelo y se mantiene separada de
una revisión humana externa, todavía pendiente.

La detección de duplicados es textual y estructural. No decide equivalencia de
teorías ni detecta contradicciones matemáticas arbitrarias. Los validadores de
transferencia comprueban registros y condiciones explícitas; el juicio científico
de cada mapa sigue necesitando revisión.

El modo de operación comprobado es a demanda y por eventos acotados. Las
plantillas de programación no equivalen a un servicio activo. La conectividad de
este sandbox impide el push directo y el conector GitHub rechaza escritura con
403; la autenticación del terminal normal puede seguir siendo válida. El estado
de publicación exige confirmación remota del commit.

La instalación editable y el uso desde el checkout son las rutas reproducibles.
Las configuraciones personales y fuentes externas no se incorporan al paquete.
Las fuentes importadas conservan sus etiquetas reportadas, sin convertirlas en
premisas hasta verificar hipótesis, auditoría y archivos.
